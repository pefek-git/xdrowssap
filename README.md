# XdrowssaP

XdrowssaP - Open Source Password generator written in C++.

### Features:

- Speed - C++ makes it fast as f**k.
  
- Customization - you can edit appearance in style.qss file, in the future i'm gonna add settings.
  
- Price - It costs 0$, it is free and of course you pay nothing!
  
- Open Source - You can see if the code has no bugs in it.
  
- Simplicity - Just pick a number of characters and just click Generate then Copy.
  
- Reliability - it just works! I can't believe it!
